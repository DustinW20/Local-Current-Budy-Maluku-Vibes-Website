## Bagian 10 — Penilaian Keseluruhan (System Usability Scale / SUS)

**Petunjuk:** Nilai pengalamanmu secara keseluruhan memakai website ini. Pakai skala 1–5 yang sama.

| No | Pernyataan | Skala 1–5 |
|---|---|---|
| S1 | Saya ingin sering memakai website ini. | |
| S2 | Menurut saya website ini terlalu rumit, padahal bisa dibuat lebih sederhana. | |
| S3 | Website ini mudah digunakan. | |
| S4 | Saya butuh bantuan orang lain (yang paham teknologi) untuk bisa memakai website ini. | |
| S5 | Fitur-fitur di website ini saling terhubung dengan baik. | |
| S6 | Ada terlalu banyak hal yang tidak konsisten (membingungkan) di website ini. | |
| S7 | Saya rasa kebanyakan orang bisa cepat belajar memakai website ini. | |
| S8 | Website ini terasa merepotkan untuk digunakan. | |
| S9 | Saya merasa percaya diri saat memakai website ini. | |
| S10 | Saya perlu belajar banyak hal dulu sebelum bisa memakai website ini. | |

> Catatan untuk peneliti (jangan ditampilkan di form): S2, S4, S6, S8, S10 adalah pernyataan negatif — memang disengaja, jangan diubah.
> Rumus skor SUS per responden: nomor ganjil → (nilai − 1); nomor genap → (5 − nilai); jumlahkan semuanya × 2,5 → skor 0–100. Skor ≥ 68 = di atas rata-rata.
